# Changelog

Each version is a git tag (`vX.Y.Z`) and a GitHub release. Pin the one you have reviewed.

## 0.3.3 — 2026-11-23

- App tools no longer walk to the globe because of "page", "tab" or "url" in their name: browsers go to the globe, then writing words (create, update, save, publish, send, write, edit, delete) win over reading, searching and web words. `notion-create-pages` types at the desk.
- Any MCP tool with "memory" in its name goes to the fridge; one that writes adds a sticky note.
- `Agent`, `SendMessage` and the task-list tools have stations of their own.
- The shell splitter and the memory-save check skip quoted text: `rg "a|b" src` is one command, `grep "=>" memory/notes.md` saves nothing.
- Tests for `world.ts` and a CI workflow (`deno test`, `claude plugin validate`).
